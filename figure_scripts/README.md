This folder contains all scripts used to generate figures from results. Details of each script can be found below.
- `00-diagnostic-functions.R`: contains custom functions for multi-panel plots for quickly checking results of a simulation.
- `00-diagnostic-plots-prey.R`: uses custom functions to view and save plots used for diagnosing simulations
- `00-vOOD-habitat.R`: contains code for creating plots used in the methods figure, in the scenarios section, formatted using the visual Overview, Design, and Details framework by Grimm et al. 2020
- `00-vOOD-movement.R`: contains code for creating plots used in the methods figure, formatted using the visual Overview, Design, and Details framework by Grimm et al. 2020
- `01-patchesvslv.R`: models and visualizes simulations results across resource density spectrum
