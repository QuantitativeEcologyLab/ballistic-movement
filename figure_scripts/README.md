This folder contains all scripts used to generate figures from results. Details of each script can be found below.
- `00-diagnostic-functions.R`: contains custom functions for multi-panel plots for quickly checking results of a simulation.
- `00-diagnostic-plots-prey.R`: uses custom functions to view and save plots used for diagnosing simulations.
- `00-vOOD-habitat.R`: contains code for creating plots used in the methods figure, in the scenarios section, formatted using the visual Overview, Design, and Details framework by Grimm et al. 2020.
- `00-vOOD-movement.R`: contains code for creating movement plot used in the methods figures.
- `00-vOOD-observations.R`: contains code for creating observation plots used in the methods figure, formatted using the visual Overview, Design, and Details framework by Grimm et al. 2020.
- `01-simoverview.R`: visualizes results of a single simulation.
- `02-npatches.R`: models and visualizes simulation results across resource density spectrum.
- `03-clustering.R`: models and visualizes simulation results across resource clustering scenarios.
- `04-calorievairance.R`: models and visualizes simulation results for variable patches.
